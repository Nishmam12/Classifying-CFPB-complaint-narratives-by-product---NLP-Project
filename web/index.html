Qwen2.5-1.5B Causal Decoder vs. Bidirectional BERT Base

Qwen2.5-1.5B demonstrates that modern autoregressive Small Language Models can be efficiently adapted to specialized financial classification tasks using parameter-efficient fine-tuning (PEFT), outperforming all six recurrent networks without requiring full weight fine-tuning.

🧩

Parameter-Efficient Adaptation (LoRA $r=16$)

By freezing the 1.54B backbone and training low-rank adapter matrices ($W = W_0 + BA$), only 18.48 million parameters (1.18%) are updated, enabling high-capacity fine-tuning on consumer-grade GPUs.

🚀

Outperforms All Recurrent Architectures

Qwen2.5 (0.7427 Macro F1) surpasses the strongest recurrent model (Bi-GRU: 0.7248) and Bi-LSTM (0.7169) by +1.8 to +2.5 percentage points by avoiding sequential memory bottlenecks.

↔️

Bidirectional vs. Causal Attention Trade-off

BERT Base achieves higher Macro F1 (0.7738 vs 0.7427) because bidirectional self-attention provides unconstrained visibility over past and future tokens simultaneously, unlike lower-triangular causal masking.

⏱️

Production Latency Considerations

BERT delivers 4.82 ms/sample versus 62.16 ms/sample for Qwen2.5 ($13\times$ speedup) and 0.10 ms/sample for Logistic Regression ($600\times$ speedup), establishing BERT as the optimal production transformer.

Core Empirical Finding: Architecture-Specific Imbalance Response

Natural Prior (untreated) achieves the highest Minority-4 F1 for both Logistic Regression (0.6829) and Bi-LSTM (0.6718). Class weighting penalizes deep neural networks (-7.9 pp on Bi-LSTM) by triggering false positives, while Random Forest is the only architecture rescued (+28.09 pp via SMOTE) by mitigating tree split skew.
