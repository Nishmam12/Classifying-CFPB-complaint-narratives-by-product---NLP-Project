Core Empirical Finding: Rejection of the Architecture-Dependence Hypothesis

Natural Prior (untreated) achieves the highest Minority-4 F1 for both Logistic Regression (0.6829) and Bi-LSTM (0.6718). Class weighting penalizes deep neural networks (-7.9 pp on Bi-LSTM) by triggering false positives, while Random Forest is the only architecture rescued (+24.3 pp) by mitigating tree split skew.
